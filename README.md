
# Lamp Studio IT Support Portal

Lamp Studio is a fictional animation studio created for a student portfolio project.

This project is a simple IT support portal designed to show how employees at an animation studio could find technical help, submit support requests, and read troubleshooting guides.

## Project Pages

### 1. Home
- Introduces the Lamp Studio IT Support Center.
- Provides navigation to the other pages.
- Gives users three ways to find support.

### 2. Support Tickets
- Allows users to submit a technical support request.
- Collects employee name, email, issue category, priority, and description.
- Displays submitted demo tickets.
- Allows users to clear saved tickets.

### 3. Help Center
- Includes six basic troubleshooting guides.
- Covers passwords, network connections, workstations, software, file access, and security.
- Includes a search feature to find articles.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- Google Fonts

## Features

- Three-page website.
- Responsive design for desktop and mobile.
- Ticket submission form.
- Ticket list saved in browser storage.
- Searchable help articles.
- Expandable troubleshooting guides.
- Simple black-and-white design.

## Important Note

Lamp Studio is a fictional company.

This is a front-end portfolio demonstration, not a real company support system. Tickets are stored only in the visitor's browser using Local Storage. There is no backend server, email notification, or real IT support team.

## How to View the Project

1. Open the GitHub repository.
2. Open the website using GitHub Pages, if enabled.
3. Visit the Home, Support Tickets, and Help Center pages.

## Purpose

The purpose of this project is to practice front-end web development and demonstrate how IT support tools can be organized into a simple website.
