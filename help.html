Help center.

Find simple guides to help solve common technology problems. Search for a topic or explore the articles below.

01 ACCOUNTS

Reset your password

Steps to take when you forget your password or need to update it.

Read guide
  1. Open your organization's account sign-in page.
  2. Select the forgot password option if it is available.
  3. Follow the instructions to verify your identity.
  4. Create a new, strong password that you do not use elsewhere.
  5. Sign in again using your new password.

If you still cannot access your account, submit a support ticket.

02 NETWORK

Fix a Wi-Fi or network issue

Try these basic steps when your internet connection is not working.

Read guide
  1. Check that Wi-Fi is turned on.
  2. Make sure you are connected to the correct network.
  3. Turn Wi-Fi off and back on.
  4. Restart your computer if the problem continues.
  5. Check whether other devices can connect.

If the issue continues, contact IT support. Do not change network equipment settings unless you are authorized.

03 WORKSTATION

Troubleshoot your workstation

Basic steps for a slow, frozen, or unresponsive computer.

Read guide
  1. Save any work that is still open.
  2. Close programs that you are not using.
  3. Check whether your computer needs an update.
  4. Restart your computer if it is safe to do so.
  5. Contact IT if the problem happens again.

Do not open or repair computer hardware unless you are authorized.

04 SOFTWARE

Software is not opening

What to check when an application will not start or keeps closing.

Read guide
  1. Close the application completely.
  2. Try opening it again.
  3. Restart your computer if needed.
  4. Check whether the application has an available update.
  5. Write down any error message you see.

If the application still does not work, submit a ticket with the error details.

05 FILE ACCESS

Request access to a shared file

What to do when you cannot open a shared folder or document.

Read guide
  1. Check that you are signed in with the correct account.
  2. Confirm that the file or folder location is correct.
  3. Check whether the file owner has shared it with you.
  4. Ask the file owner to confirm your access permissions.
  5. Contact IT support if you still cannot access it.

Include the file or folder name when submitting a request. Never share your password.

06 SECURITY

Report a suspicious email

Learn what to do if you receive a message that looks suspicious.

Read guide
  1. Do not click suspicious links or open unexpected attachments.
  2. Do not reply or provide personal information.
  3. Do not enter your password through a link in the message.
  4. Report the email using your organization's approved reporting process.
  5. If you already clicked a link or shared information, contact IT immediately.

When in doubt, do not interact with the message. Report it to the appropriate support team.
